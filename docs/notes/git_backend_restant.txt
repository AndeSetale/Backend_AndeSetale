Workflow pour chaque branche
bash
# 1. Créer la branche depuis develop à jour
git checkout develop && git pull origin develop
git checkout -b feature/nom-de-la-fonctionnalite

# 2. Travailler, committer
git add .
git commit -m "feat(incidents): ajoute GET /api/incidents/<id>/"

# 3. Pousser et ouvrir une PR vers develop
git push -u origin feature/nom-de-la-fonctionnalite

# 4. Une fois la PR mergée, nettoyer localement
git checkout develop && git pull
git branch -d feature/nom-de-la-fonctionnalite

En fin de sprint, une fois toutes les features du sprint mergées dans develop et testées :

bash
git checkout develop && git pull
git checkout -b release/1.1.0
# tests finaux, corrections mineures éventuelles
git checkout main && git merge release/1.1.0 --no-ff
git tag v1.1.0
git checkout develop && git merge release/1.1.0 --no-ff
git branch -d release/1.1.0
